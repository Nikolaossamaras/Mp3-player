# Mp3-player
>this reposetory includes the BOM file ,the step files, the pcb files and the firmware for my first ever mp3-player

## Why i made it
This past month i don't have really good internet at home but i still want to listen to music so that a reason why i build this project. Another reason was that i don't want to listening to those annoying ads of spotify nor pay for the premiumm. Having an mp3 player as an accessory also drawed my attention and having a custom one seemed a ton more cool

## does it have something special
To be honest it does not have any new/special function , but the thing that makes it special for me is that i made it myself and that i will now have an accessory that is cool and functionable.
